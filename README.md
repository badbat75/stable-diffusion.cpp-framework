# stable-diffusion.cpp-framework

> **Windows only** — all scripts are PowerShell (.ps1) and target Windows 10/11 exclusively.

PowerShell scripts to build and run [stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp) on Windows with multi-GPU backend support (CUDA, Vulkan, ROCm/HIP) and NSIS installer packaging. The web UI built into `sd-server` is used as the frontend — no separate UI is bundled. Mirrors the sibling [llama.cpp-framework](https://github.com/) repo one-to-one (same script names, same INI layout, same install-time flow).

## Prerequisites

- Windows 10/11
- [Visual Studio](https://visualstudio.microsoft.com/) with C++ workload
- [Git](https://git-scm.com/)

Optional (installed automatically by scripts as needed):
- [CUDA Toolkit](https://developer.nvidia.com/cuda-toolkit)
- [Vulkan SDK](https://vulkan.lunarg.com/)
- [AMD HIP SDK (ROCm)](https://rocm.docs.amd.com/)
- [NSIS](https://nsis.sourceforge.io/) (for installer packaging, installed via winget if missing)

## Quick start

```powershell
# 1. Install / update the toolchain (elevates via UAC as needed).
#    Re-run any time to upgrade winget packages and pull stable-diffusion.cpp.
.\00-install-prerequisites.ps1

# 2. Auto-detect paths and generate config-build.psd1
.\01-configure.ps1

# Or override the stable-diffusion.cpp source clone location:
.\01-configure.ps1 -StableDiffusionCppDir "C:\path\to\my\stable-diffusion.cpp"

# 3. Build stable-diffusion.cpp
.\02-build.ps1

# 4. Produce a Windows installer in dist\
.\03-package.ps1
```

## Layout

All build artifacts live under `build\` so a single `rm -rf build\` returns the repo to a clean state.

```
<repo>/
├── build/
│   ├── config-build.psd1            ← build-time config (generated by 01-configure.ps1)
│   ├── stable-diffusion-cpp.nsi     ← NSIS script (generated by 03-package.ps1, transient)
│   ├── stable-diffusion.cpp/        ← sd.cpp source clone (StableDiffusionCppDir, --recursive)
│   ├── cmake-build/                 ← cmake binary dir (out-of-source build)
│   └── staging/                     ← cmake staging area for NSIS
├── dist/                            ← final installer .exe
├── resources/                       ← scripts shipped inside the installer
└── *.ps1                            ← top-level build/run/package scripts
```

## Configuration

Settings are split between build-time and runtime so the same scripts work both in-tree and from a system install.

| File | Where | Purpose |
|------|-------|---------|
| `config-build.psd1` | `build\` (gitignored) | Build-time paths and GPU backend toggles. Generated by `01-configure.ps1`. |
| `server.ini` | `%LOCALAPPDATA%\stable-diffusion.cpp\config\` | Machine-wide sd-server runtime (port, host, threads, models dir). Single `[Server]` section. Generated by `resources\config-server.ps1`. |
| `presets.ini` | `%LOCALAPPDATA%\stable-diffusion.cpp\config\` | Per-model presets: one `[<model-id>]` section each with model path, sub-model paths (vae, llm, t5xxl, clip_l, clip_g), memory knobs (offload, mmap, fa, max-vram), and default generation params (sampler, steps, cfg-scale, width, height). Translated into sd-server CLI args at launch time by `run-server.ps1`. Generated by `resources\config-model.ps1`. |

`config-build.psd1` keys:

| Section | Keys |
|---------|------|
| Paths | `StableDiffusionCppDir`, `HipPath`, `VsDevShell`, `CacheDir` |
| GPU backends (at most one true) | `SdCuda`, `SdVulkan`, `SdHipblas` |
| Build | `BuildType` |

Runtime configs are written on first launch (or by the NSIS install-time page). They can be regenerated at any time via the Start Menu shortcuts (*Configure sd-server*, *Configure model*) shipped with the installer — each shortcut runs the interactive writer once and the window closes when you're done.

## Scripts

| Script | Description |
|--------|-------------|
| `00-install-prerequisites.ps1` | Idempotent toolchain bootstrapper. Installs missing winget packages (PowerShell 7+, NSIS) and upgrades present ones in a single UAC-elevated session; pulls stable-diffusion.cpp source (with submodules) when cloned; flags CUDA / Vulkan / HIP SDKs for manual install; reports version changes and recommends a rebuild only when sd.cpp source moved. |
| `01-configure.ps1` | Detects environment, verifies tools, auto-probes GPU toolchains, writes `config-build.psd1`. Accepts `-StableDiffusionCppDir`. |
| `02-build.ps1` | CMake configure (out-of-source into `build\cmake-build\`) + Ninja build. Auto-clones stable-diffusion.cpp `--recursive` into `build\stable-diffusion.cpp\` (ggml submodule). Throws if more than one GPU backend toggle is on. |
| `03-package.ps1` | Stages from `build\cmake-build\bin\` into `build\staging\`, then runs NSIS to produce `dist\stable-diffusion-cpp-<version>-win64-setup.exe`. |
| `common.ps1` | Shared bootstrap: loads `$cfg` from `config-build.psd1`, prepends ROCm `bin\` to PATH, exposes `Enable-VsDevShell` as a function. VS Dev Shell activation is **opt-in** — only build/package scripts call it, runtime scripts don't pay the startup cost. |
| `resources\run-server.ps1` | Runtime entry point shipped with the installer. Reads `server.ini` + `presets.ini`, picks one preset (auto if only one, interactive picker otherwise; `-Preset <id>` skips the prompt), translates it into sd-server CLI args, and launches sd-server. The user interacts with sd-server's built-in web UI at `http://<host>:<port>/`. Accepts `-ServerExe` to override the sd-server binary location. |
| `resources\config-server.ps1` / `config-model.ps1` | Interactive config writers for the user-scope INI files (`server.ini` / `presets.ini`). Each supports `-NonInteractive` so NSIS can call them at install time. `config-model.ps1` does section-preserving edits — hand-edits to other sections survive. |
| `resources\common-functions.ps1` | Shared INI parser/writer for `server.ini` (`Read-ServerIni`, `Set-ServerIniField`). Dot-sourced by all three runtime scripts. |

## Packaging

`03-package.ps1` produces a Windows installer at `dist\stable-diffusion-cpp-<version>-win64-setup.exe`. The installer:

- Installs stable-diffusion.cpp binaries to `C:\Program Files\stable-diffusion.cpp\`.
- Optionally adds `bin\` to the system PATH.
- Creates Start Menu shortcuts (`stable-diffusion.cpp`, *Configure sd-server*, *Configure model*, *Uninstall*) targeting `pwsh.exe` (PowerShell 7+).
- Prompts for sd-server port + bind + thread count + models folder during install (machine-wide knobs); per-model parameters (paths, sampler, steps, cfg, etc.) are collected lazily on first launch via `config-model.ps1`.
- Supports upgrades (silently uninstalls the previous version first).
- Includes a full uninstaller in Add/Remove Programs. By default it preserves `%LOCALAPPDATA%\stable-diffusion.cpp\` (configs, logs) across uninstalls; the user can opt in to a full wipe.

NSIS is installed automatically via winget if not already present.

## GPU backend notes

Only one GPU backend may be active per build (CUDA, Vulkan, or HIP). `01-configure.ps1` auto-probes for the installed toolchains and picks one with priority **CUDA > Vulkan > HIP**, writing the matching toggle to `config-build.psd1`. Edit the `.psd1` to force a different backend.

### CUDA
Requires NVIDIA GPU with a recent CUDA Toolkit installed; `nvcc` must be on PATH after VS Dev Shell activation.

### Vulkan
Works on any GPU with up-to-date Vulkan drivers. Needs the Vulkan SDK (provides `glslc.exe`); auto-detected via `VULKAN_SDK` env var or `%ProgramFiles%\VulkanSDK\*\Bin\glslc.exe`.

### ROCm / HIP
Requires AMD GPU with ROCm drivers. On Windows ROCm support is limited to specific AMD GPUs (typically RX 6000-series and newer). `02-build.ps1` switches to the HIP-bundled clang when `HIP_PATH\bin\clang.exe` exists.
